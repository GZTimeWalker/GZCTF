# 独立题库完整编辑器设计

## 目标

管理员在管理工作台的“题目管理”创建独立题目，选择 Web、Misc 等 CTF 分类和四种运行方式，配置题面、Flag、附件或容器、提示与题解。配置完成后选择技能树及其全局类别发布。学员加入技能树后，能从类别打开题目介绍、启动容器或下载附件并提交 Flag。

比赛动态计分、一血奖励、比赛截止时间和比赛队伍不进入独立题库。独立题目可被多棵技能树复用。

## 数据与边界

- `Features/ChallengeLibrary/Domain/Challenge` 是唯一的独立题目实体。增加结构化 `ChallengeCategory CtfCategory`，默认 Misc；既有导入题目从来源元数据里的 `category` 回填，无法识别时使用 Misc。通过迁移持久化，不靠题面或不透明 JSON 存放分类。
- 现有 `ChallengeType` 继续表示静态附件、静态容器、动态附件、动态容器。CTF 分类与技能树的“全局类别”是两种不同维度：前者表示 Web/Misc 等赛题方向，后者决定题目在技能树中的位置。
- 题目 API 的创建、列表、编辑响应和更新命令暴露 `ctfCategory`。保留现有难度、启用状态、本地化题面、Flag、提示、题解与运行配置字段。已发布题目的运行方式不可更改。
- 运行配置用已存在的 `RuntimeConfigurationJson` 持久化，但管理 UI 使用有类型的表单；服务端在保存和发布时校验配置。容器字段沿用运行时读取的 `ContainerImage`、`ExposedPort`、`Cpu`、`MemoryMb`、`StorageMb`、`NetworkMode`、`FlagTemplate`；附件池沿用 `Attachments` 中的文件名、SHA-256 和 Flag。
- 上传使用现有管理员资产 API，题目保存可被运行时读取的存储键。静态附件允许没有文件的纯题面题，或一个文件与多个静态 Flag；动态附件维护多组文件、SHA-256、对应 Flag。静态容器允许多个静态 Flag；动态容器使用模板生成用户专属 Flag。历史附件 URL 会转换为实际存储键，下载时保留原文件名。
- 题目可设置每名学员的提交次数上限，0 表示不限次数。容器启动后的响应返回可访问地址，管理员试运行也显示该地址。
- “上题”有两个状态：发布把题目关联到所选技能树类别，启用开关控制已发布题目的可见性。题目在已发布技能树内且自身已发布并启用时，学员才看得到并能通过直接 API 使用。关闭或退休后旧直链也不能启动、下载或验证 Flag；管理员编辑和试运行保留受控入口。

## 管理员流程

1. 在“题目管理”打开创建面板，填写标题、CTF 分类、运行方式；创建独立草稿并进入详情编辑页。
2. 编辑页按“基本信息 / 运行环境与附件 / Flag / 提示与题解”分区。每种运行方式只展示适用的字段，显示已保存状态、表单错误和预览。移动端分区纵向排列。
3. 管理员保存草稿；可在详情页试启动和停止容器实例，或预览学员题面与附件信息。
4. 点击发布后选技能树，再选该树下的一个或多个全局类别；没有类别时沿用现有内联建类别能力。发布写入题目与类别关系，保留修订冲突检查。若技能树本身尚未发布，界面明确提示需要发布技能树后学员才可见。
5. 管理列表按 CTF 分类筛选，显示运行方式、发布状态和启用状态；启停需要确认并在成功后刷新列表和技能树缓存。编辑、退休入口保持明确。

## 学员流程

学员从技能树详情选择类别与题目，进入现有 `ChallengeWorkspace`。页面展示题目简介和 Markdown 说明；容器题可启动、续期和停止实例，附件题可下载，所有题型可提交 Flag。提示与题解按现有记录规则展示。静态题提交的 Flag 与任一有效静态 Flag 比较；动态题使用分配给当前用户的附件或容器 Flag。

## 错误与安全

- 创建和保存拒绝空标题、非法分类、运行方式不匹配的 Flag 或缺失的容器/附件配置。失败时保留表单输入。
- 发布前检查题目存在有效题面、所需 Flag 与运行配置、实际存在的附件、至少一个有效技能树类别。409 冲突只提示刷新核对，不自动用新版本重复提交。
- 上传失败不写入损坏的附件引用；已保存题目在用户作答期间修改时，不把当前学员实例静默改成另一种运行方式。
- 普通用户直接调用题目详情、实例、附件、提示、题解或提交 API 时，题目必须已发布且启用；技能树页面另外验证学员加入状态。管理员可预览未发布题目。

## 验收

- 创建 Web/Misc 等分类和四种运行方式的题目；保存、重新打开后字段一致。
- 静态多 Flag、动态附件分配、动态容器模板和容器配置按运行方式工作；上传附件可由学员下载。
- 选树选类别发布后，学员能从技能树进入题目并完成一次解题；停用、退休和未发布题目不再可访问。
- 旧版导入题目仍可编辑，保留原始 CTF 分类；双语、窄屏、加载、空状态、失败与冲突反馈可用。
